Launch Config Scanner on this Windows PC
==========================================

1. Download Launch-ConfigScanner.exe (this folder).
2. Put the repo tools\ folder next to it (Encryptor, BiOS2_PackageGenerator).
   Or unzip lab_pack.zip instead (exe + tools already together).
3. Double-click Launch-ConfigScanner.exe.

Includes auto SMB login for lab cabinets (10.0.0.111\test / test).
Window title stamp is baked at build time (see title bar).
